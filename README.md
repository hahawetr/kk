# 小龍音標島：音霧跑跑

GitHub Pages 可用的單頁遊戲原型，不需安裝套件。將 `index.html` 放在 repository 根目錄即可。

## 遊戲規則

- 小龍自動在漂浮島上向右奔跑；魔怪會隨機出現。
- 遇到魔怪後畫面暫停，單字顯示在上方；魔怪噴出三朵雲，雲上是三組完整 KK 音標。
- 答對後繼續前進；答錯扣一顆心，還有心就留在原題重答；三顆心用完，本章暫停並顯示失敗畫面。
- 每章十次魔怪挑戰，共三章；每章從 18 個常用單字中抽題，54 個單字不會在同一章重複。
- 遊戲選單可隨時暫停、繼續、重玩本章或打開 KK 小抄；小抄包含常見音標符號與全部 54 個單字的讀音索引。
- 每章開始可選武器：回音法杖讓重播發音變慢；星羽弓每三次連續答對多得一顆星塵；稜鏡砲每章可消除一朵錯誤雲。武器不會免除答錯扣心。
- 星塵和龍等級存在目前瀏覽器的 `localStorage`。

## 更新到 GitHub

解壓縮部署包，把裡面的 `index.html` 上傳到 repository 根目錄並選擇覆蓋舊版，再 Commit changes。若 GitHub Pages 已啟用，更新 main 分支後會自動重新部署。
